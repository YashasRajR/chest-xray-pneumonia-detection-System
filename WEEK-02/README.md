# WEEK 02: UI/UX & Color Theory

## Objectives
- Transition focus from backend machine learning to frontend User Interface design.
- Study color theory specifically tailored for clinical/medical dashboards.
- Develop the initial static HTML/CSS wireframes for the Pneumonia Detection System (PDS).

## Design Philosophy
Medical interfaces require absolute clarity and minimal cognitive load. The design language established this week focused on:
- **Clinical Minimalism:** Removing unnecessary borders, heavy shadows, or distracting animations.
- **Color Coding:** Establishing stark, binary visual indicators. Deep Green (`#2e7d32`) was selected to represent "NORMAL" (Safe), while a highly visible Red (`#c62828`) was chosen for "PNEUMONIA" (Danger/Alert).

## Technical Details
- Built static web pages utilizing semantic HTML5.
- Applied responsive CSS Flexbox layouts to ensure the dashboard would function on both 1080p desktop monitors and smaller tablet viewports used by medical technicians.

## Deliverables
- Static wireframes located in the `web page(PDS)` directory.
- Color theory documentation and CSS variable definitions.
