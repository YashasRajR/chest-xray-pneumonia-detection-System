# Eye & Head Movement Module

Part of Human Behavior Tracking System.

## Features

- Eye Tracking
- Blink Detection
- Blink Rate Estimation
- Eye Open/Close Detection
- Iris Detection
- Gaze Tracking
- Gaze Direction Estimation
- Head Pose Estimation
- Head Direction Detection
- JSON Output Generation

## Technologies Used

- Python
- OpenCV
- MediaPipe Face Mesh
- NumPy

## Output Files

- eye_output.json
- head_output.json
