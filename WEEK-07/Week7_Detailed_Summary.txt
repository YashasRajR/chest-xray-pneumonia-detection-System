During week seven, I focused heavily on quality assurance and finding ways to break the Flask backend server. I wanted to make sure that the pneumonia detection system was robust enough to handle unexpected inputs. I spent a lot of time conducting destructive testing to see where the system would fail. For instance, I took a standard PDF document, renamed it to have a dot jpg file extension, and tried to upload it to the server. I also tried sending malformed JSON data, and I even tested the system's memory limits by injecting massive twenty-megabyte files. 

Whenever the server crashed or struggled with these bad inputs, I went into the code and built safeguards. A major part of this was implementing strict MIME-type validation. Instead of just trusting the file extension on the upload, the server now actively checks the actual media type of the uploaded file. If someone tries to upload a fake or malicious payload, the server safely intercepts it and gracefully rejects it by returning a 415 Unsupported Media Type error instead of completely crashing. This testing and hardening process made the entire backend architecture much more secure and reliable.
